## About
To get myself familiar with Next.js, I created a image gallery that allows users to create albums and add images. The website allows all viewers to see public albums from all users. Image upload is blocked for new users but you can sign in and create albums

## Development
This app was build using the following technologies
* Next.js 
* Postgres
* drizzle ORM
* Clerk
* PostHog Analytics
* Shadui
